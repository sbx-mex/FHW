# Power BI · FHW Cada Taza Cuenta

Implementación rápida para el reporte FHW en Power BI Desktop.

- `HTML_Tienda_Completo.dax`: una sola medida HTML autónoma para completar la página Tienda. Incluye CTC, movimiento semanal, FHW, Bebidas Lobby, cobertura y siguiente instrucción.
- `SEGMENTADORES_CONECTADOS.md`: configuración de Región, DM, Tienda y Semana conectada entre páginas.

La tabla usada por el PBIX actual se llama **FHW_Modelo**. No renombrarla ni duplicar las medidas existentes.
